# Evernote notes (retired)

Casebook no longer has an Evernote integration. The Evernote block panel, the `casebook evernote` commands, the Evernote note tools for AI clients and ENEX files were removed on 2026-10-27.

To put a question's findings in Evernote or any other notes or document app, copy or save the summary from **Share the answer**, use `casebook report` (`--brief` for the leadership brief), or ask your AI client to save it to an app it is already connected to. [Using a question summary in other apps](sharing.md#using-a-question-summary-in-other-apps) explains each path, and [If you used Evernote notes](sharing.md#if-you-used-evernote-notes) covers what changed for existing questions.

A source recorded with the source type "Evernote note" keeps that label. Notes you posted earlier stay in your Evernote account, unchanged.

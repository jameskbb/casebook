# Evernote notes (retired)

Casebook no longer has an Evernote integration. The Evernote block panel, the `casebook evernote` commands, the Evernote note tools for AI clients and ENEX files were removed on 2026-10-27 ([ADR 0024](decisions/0024-portable-output-instead-of-evernote.md)).

To put a case's findings in Evernote or any other notes or document app, copy or save the summary from **Share summary**, use `casebook report` (`--brief` for the leadership brief), or ask your AI client to save it to an app it is already connected to. [Using a case summary in other apps](sharing.md#using-a-case-summary-in-other-apps) explains each path, and [If you used Evernote notes](sharing.md#if-you-used-evernote-notes) covers what changed for existing cases.

Evidence recorded with the source type "Evernote note" keeps that label. Notes you posted earlier stay in your Evernote account, unchanged.
